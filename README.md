# VFS – Виртуальная файловая система на Python

**VFS** – это простая виртуальная файловая система, реализованная на Python с использованием XML для хранения структуры файлов и папок. Проект предоставляет интерфейс командной строки для работы с файлами и папками внутри виртуальной файловой системы.

---

## Описание

VFS позволяет:
- Создавать и управлять виртуальной файловой системой.
- Выполнять базовые команды: `ls`, `cd`, `rm`, `vfs-info`, `vfs-save`.
- Загружать, изменять и сохранять состояние файловой системы в XML.

---

## Возможности

- **Поддержка скриптов**: выполнение команд из файла скрипта.
- **XML-хранилище**: сохранение и загрузка состояния файловой системы.
- **Графический интерфейс**: приложение с поддержкой команд.

---

## Установка

### Требования

- Python 3.x
- Библиотеки: `tkinter`, `xml.etree.ElementTree`, `base64`, `hashlib`

### Запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ha1fisch1337/VFS.git
   cd VFS
   ```

2. Запустите основной скрипт:
   ```bash
   python main.py [-p путь_к_XML] [-s путь_к_скрипту]
   ```
   - `-p`: путь к XML-файлу с описанием файловой системы.
   - `-s`: путь к файлу скрипта для автоматического выполнения команд.

---

## Использование

### Доступные команды

| Команда      | Описание                                      |
|--------------|-----------------------------------------------|
| `ls`         | Вывести список файлов и папок.                |
| `cd <путь>`  | Перейти в указанную папку.                    |
| `rm <имя>`   | Удалить файл или папку.                       |
| `rm -r <имя>`| Рекурсивно удалить папку.                    |
| `vfs-info`   | Вывести информацию о файловой системе.       |
| `vfs-save`   | Сохранить текущее состояние в `saved_vfs.xml`.|
| `whoami`     | Вывести имя текущего пользователя.            |
| `uptime`     | Вывести время работы системы.                |
| `clear`      | Очистить экран.                               |
| `exit`       | Выйти из приложения.                          |

---

### Пример работы

1. Загрузите файловую систему:
   ```bash
   python main.py -p example_vfs.xml
   ```
2. В интерактивной консоли выполните команды:
   ```
   ls
   cd folder_name
   vfs-info
   ```
